# Abacus — fonds clairs et foncés

Le mot-symbole SVG provient du logo vectoriel publié dans l’en-tête de
https://www.abacus.ch/en (consulté le 28 octobre 2026). Les tracés sont conservés.
La version négative suit la règle officielle `inverted-header` du site :
`path`, `polygon` et `rect` en blanc. Les remplissages sont des attributs SVG,
sans filtre CSS. Le symbole négatif utilise les mêmes tracés avec un cadrage
sur le pictogramme. Le symbole positif est l’original « Abacus logo RGB.png »
fourni par Alex ; le mot-symbole positif existant est conservé.

Offres : négatif sur fond foncé ; positif pour le corps clair du thème Helvetia.
Communes : symbole négatif sur fond foncé, positif pour Helvetia.
